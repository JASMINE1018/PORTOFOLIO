Full-stack developer adalah pengembang yang bekerja pada dua sisi pembuatan aplikasi, yaitu Frontend untuk tampilan dan pengalaman pengguna, serta Backend untuk logika, server, dan pengelolaan data. Dengan kemampuan di kedua area, mereka dapat memahami keseluruhan alur kerja sebuah aplikasi. Illustrator adalah kreator visual yang membuat gambar atau ilustrasi untuk berbagai kebutuhan, baik di media cetak maupun digital. Mereka mengembangkan gaya visual, merancang konsep, dan menyampaikan pesan melalui karya yang mereka hasilkan.

Tentang Saya

"Saya merupakan pelajar dari SMKN 1 Surabaya yang memiliki minat besar dalam bidang pengembangan perangkat lunak. Saat ini, saya tengah mempelajari berbagai hal baru di ranah Full-Stack Development, serta mengeksplorasi bidang lain seperti Game Development dan Ilustrasi digital. Fokus utama saya saat ini adalah Web Development, namun saya juga berkeinginan untuk memperdalam pengetahuan di dunia pengembangan game. Selain itu, saya memiliki hobi menggambar dan menciptakan karya kreatif lainnya. Saya memilih jurusan Rekayasa Perangkat Lunak (RPL) karena ingin mewujudkan impian untuk menggabungkan kreativitas dan logika dalam satu kesatuan yang harmonis."

Keahlian

HTML

HTML adalah bahasa pemrograman, padahal bukan. HTML adalah kependekan dari Hypertext Markup Language yang merupakan sebuah bahasa markup.

CSS

CSS adalah singkatan dari Cascading Style Sheets. Ini adalah merupakan bahasa pengkodean yang memberikan tampilan dan tata letak situs web. Seiring dengan HTML, CSS adalah dasar untuk desain web.

Javascript

JavaScript adalah salah satu bahasa pemrograman populer dan sering digunakan dalam pengembangan web. Bahasa ini memungkinkan developer untuk menciptakan elemen web dinamis dan interaktif, seperti animasi, formulir, live chat, dan banyak lagi.

Python

Python merupakan bahasa pemrograman komputer yang biasa dipakai untuk membangun situs, software/aplikasi, mengotomatiskan tugas dan melakukan analisis data. Bahasa pemrograman ini termasuk bahasa tujuan umum.

Ibis Paint

Ibis Paint adalah salah satu aplikasi desain grafis dan menggambar yang populer di kalangan pengguna smartphone dan tablet. Dengan antarmuka yang ramah pengguna dan beragam fitur canggih

Medibang Paint

Aplikasi Medibang paint merupakan software atau aplikasi digital painting dan comic creator.
